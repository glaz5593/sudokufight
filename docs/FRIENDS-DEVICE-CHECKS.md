# משחק עם חברים (1.0.4): בדיקות בשני טלפונים (למשה)

הבדיקות שמשלימות את תנאי ה"סיום" של שלב 14ג (`docs/02-WORK-PLAN.md`), ושאי אפשר להריץ ב־Jest. הרשימה: `docs/handoff/2026-10-19/friends-room.md`, סעיף 10 ("במכשיר"), עם ברירות המחדל שאישרת ב־20.10.2026 ("כן כן כן, לך עם ברירות המחדל, תמשיך לבנות"). הכללים: אפיון, סעיף 5.4.
מה שאפשר לבדוק בלי טלפון כבר נבדק אוטומטית: `apps/server/test/friendsHost.contract.test.ts` מריץ את הקוד של האפליקציה מול השרת האמיתי. הוא פותח חדר, מוצא את הקוד בתוך הודעה שלמה בעברית, מצטרף, מתחיל, משחק משחק שלם, ובודק את ההיסטוריה, ה־Replay, הרקע, ההוצאה והיציאה. בנוסף, יש בדיקות לחדר, לשירות, לקוד, לקישורים ולמסכים.

> **בקצרה: קודם השרת, ורק אחר כך האפליקציה.** השרת של 1.0.4 עולה ל־Staging (עם migration ‏0009), ורק אז APK ‏1.0.4 מול Staging. כל אחד מהם רק באישור שלך. אפליקציה חדשה מול שרת ישן מציגה "האפשרות הזו עוד לא זמינה."
> **1.0.4 הוא APK עם שינוי native** (הקישורים שפותחים את האפליקציה, וההעתקה). לכן זו בנייה מלאה, ארוכה יותר, שתופסת יותר מקום בכונן C (‏[`BUILD-APK.md`](BUILD-APK.md), "כשהדיסק מלא"). בודקים ב־**Release build** (‏`npm run apk`), לא ב־Development Build.
> **שני טלפונים, שני חשבונות.** כל טלפון עם חשבון משלו. בכל מקום כתוב "טלפון א'" (המארח, אתה) ו"טלפון ב'" (החבר, Dana).
