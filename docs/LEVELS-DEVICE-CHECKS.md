# אימון בשלבים (1.0.2): בדיקות במכשירים (למשה)

הבדיקות שמשלימות את תנאי ה"סיום" של שלב 14א (`docs/02-WORK-PLAN.md`), ושאי אפשר להריץ ב־Jest. הרשימה: `dev-plan.md` סעיף 3.2 (‏`docs/handoff/2026-10-15/staged-practice/`), עם התשובות של משה מ־18.10.2026.
מה שאפשר לבדוק בלי טלפון כבר נבדק אוטומטית: `levels.e2e.test.tsx` ו־`ideas.test.tsx` משחקים באפליקציה מקצה לקצה (משחק חדש ← מפה ← שלב ← תוצאה ← מפה, ופרקים 1–3, 4, 7 ו־9). ‏`apps/server/test/appLevels.contract.test.ts` מריץ את הסנכרון של האפליקציה מול השרת האמיתי, ו־`npm run levels:validate` בודק את 300 השלבים.

> **בקצרה: קודם השרת, ורק אחר כך האפליקציה.** השרת של 1.0.2 עולה ל־Staging, ורק אז APK ‏1.0.2 מול Staging (‏[`RELEASE-CHECKLIST.md`](RELEASE-CHECKLIST.md), "גרסה 1.0.2"). כל אחד מהם רק באישור שלך.
> בודקים ב־**Release build** (‏`npm run apk`, ‏[`BUILD-APK.md`](BUILD-APK.md)), לא ב־Development Build: שם הזמנים, האנימציות והמסך הדלוק שונים.
> **תמיד עם חשבון מחובר.** בלי חשבון שום דבר לא נשמר, והמפה מתחילה בשלב 1.

## בדיקה 11: המתגים של גרסת הבדיקה (רק ב־staging)
