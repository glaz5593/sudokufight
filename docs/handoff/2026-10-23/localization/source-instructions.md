# Sudoku Fight — הוראות הוספת שפות

מסמך הוראות לביצוע. המטרה: לתרגם את האפליקציה כולה ואת דפי החנות ב־Google Play וב־App Store לכל השפות ברשימה, לפי הסדר.

שפות קיימות שלא נוגעים בהן: אנגלית (שפת המקור) ועברית.

---

## 1. כללי יסוד — חלים על כל שפה

**מתרגמים הכול.** כל טקסט שהמשתמש רואה: מסכים, כפתורים, הודעות שגיאה, התראות, דיאלוגים, מסכי הדרכה והוראות המשחק, הודעות מערכת במשחק החי, מסכי פרופיל ודירוג, מסך הדיווח והחסימה, מדיניות הפרטיות ותנאי השימוש (אם מוצגים באפליקציה), וגם **שמות כל הארצות** שמופיעים באפליקציה.

**שם המותג לא מתורגם.** השם

```
Sudoku Fight
```

נשאר באותיות לטיניות בכל השפות. מה שבא אחריו (למשל החלק התיאורי בשם החנות) כן מתורגם.

**לא משאירים מחרוזות מקודדות בקוד.** לפני שמתחילים, לעבור על כל הקוד ולוודא שכל טקסט נמצא בקובץ המחרוזות. כל מחרוזת שנמצאת ישירות בקוד מועברת קודם לקובץ המשאבים.

**לא מחברים מחרוזות.** לא בונים משפט מחלקים. משתמשים במחרוזת אחת עם מצייני מקום ממוספרים:

```xml
<string name="match_won">%1$s ניצח את %2$s</string>
```

כך כל שפה יכולה לסדר את המשפט בסדר המילים שלה.

**ריבוי (plurals).** כל מחרוזת עם מספר (נקודות, ניצחונות, דקות, שחקנים) חייבת להיות משאב ריבוי ולא מחרוזת רגילה:

```xml
<plurals name="wins_count">
    <item quantity="one">%d win</item>
    <item quantity="other">%d wins</item>
</plurals>
```

לכל שפה למלא בדיוק את הצורות שהיא צריכה (ראו פירוט בסעיף 4).

**שמות ארצות.** עדיף לא לתרגם ידנית אלא להפיק אותם מהמערכת לפי קוד הארץ, כך שהם מתורגמים אוטומטית לכל שפה:

```kotlin
Locale("", countryCode).getDisplayCountry(currentLocale)
```

אם יש רשימת ארצות קבועה בקובץ, לתרגם את כולה לכל שפה.

**תאריכים, שעות ומספרים** מעוצבים לפי השפה בעזרת כלי העיצוב של המערכת, לא ידנית.

**הספרות על לוח הסודוקו** נשארות ספרות מערביות 1–9 בכל השפות, כולל ערבית ותאית.

**מילון מונחים.** לפני התרגום, לבנות מילון מונחים קבוע לכל שפה ולהשתמש בו בעקביות: משחק, יריב, ניצחון, הפסד, תיקו, דירוג, חדר, הזמנה, משבצת, שורה, עמודה, ריבוע, רמז, טעות, דיווח, חסימה.

**פנייה לשחקן.** בכל שפה שיש בה הבחנה בין פנייה רשמית לחופשית — להשתמש בפנייה החופשית והידידותית, באופן עקבי לאורך כל האפליקציה (חריגים מצוינים בסעיף 4).

**בורר שפה באפליקציה.** כל שפה מוצגת ברשימה בשמה בשפה עצמה, למשל:

```
Deutsch
Español
العربية
日本語
```

## 4. הוראות מיוחדות לכל שפה

### ערבית
- **כיוון ימין לשמאל.** לבדוק כל מסך: היפוך פריסה, חצים ואייקונים כיווניים, מחווני התקדמות.
- **הלוח עצמו לא מתהפך.** לוח הסודוקו נשאר באותו מבנה כמו באנגלית.
- **ריבוי בשש צורות:**

```
zero, one, two, few, many, other
```

- ספרות מערביות על הלוח. בטקסט הרגיל — להשאיר לפי ברירת המחדל של המערכת.
- ערבית ספרותית מודרנית, לא ניב מקומי.
- הטקסט מתארך בכ־25%. לבדוק שאין חיתוך בכפתורים.
- לוודא שהגופן תומך בערבית ושהאותיות מחוברות כראוי.

### ספרדית
- ספרדית לטינו־אמריקאית ניטרלית לאפליקציה. בחנויות: למלא גם את הגרסה הלטינית וגם את גרסת ספרד (מותר להעתיק עם התאמות קלות).
- סימני שאלה וקריאה הפוכים בתחילת משפט.
- פנייה ב־tú.
- הטקסט מתארך בכ־25%.

### פורטוגזית (ברזיל)
- פורטוגזית ברזילאית בלבד, לא אירופית.
- פנייה ב־você.
- הטקסט מתארך בכ־25%.

### גרמנית
- **מילים ארוכות מאוד** והטקסט מתארך עד 35%. לבדוק כל כפתור, כותרת וטאב שאין חיתוך.
- פנייה ב־du.
- שמות עצם תמיד באות גדולה.

### צרפתית
- רווח לא נשבר לפני סימנים:

```
! ? : ;
```

- פנייה ב־tu.
- הטקסט מתארך בכ־20%.

### יפנית
- אין רווחים בין מילים. לבדוק ששבירת שורות לא קוטעת מילים באמצע.
- **חריג לפנייה:** להשתמש בלשון הנימוס הסטנדרטית (סיומות です/ます), לא בלשון חופשית.
- אין ריבוי — צורת other בלבד.
- לוודא שהגופן מציג תווים יפניים כראוי ולא סיניים.

### רוסית
- **ריבוי בשלוש צורות עיקריות:**

```
one, few, many, other
```

- מילים ארוכות, הטקסט מתארך עד 30%.
- לנסח משפטים שלא מחייבים לדעת את מין השחקן (פעלי עבר ברוסית משתנים לפי מין).

### קוריאנית
- **חריג לפנייה:** לשון נימוס (존댓말).
- אחרי שם שחקן או מילה שמוכנסת דינמית, מילית היחס בקוריאנית משתנה לפי האות האחרונה. לנסח כך שהמילית לא תבוא מיד אחרי מציין מקום.
- אין ריבוי — צורת other בלבד.

### איטלקית
- פנייה ב־tu.
- הטקסט מתארך בכ־20%.

### טורקית
- **בעיה טכנית חשובה:** האותיות i ו־ı שונות בטורקית. כל המרה לאותיות גדולות או קטנות בקוד חייבת להיות תלוית שפה:

```kotlin
text.uppercase(Locale.getDefault())
```

ולא המרה ללא ציון שפה.

- סיומות בטורקית משתנות לפי הניקוד של המילה הקודמת. לא להצמיד סיומת ישירות לשם שחקן דינמי.
- פנייה ב־sen.

### סינית מפושטת
- **הערה:** Google Play לא זמין בסין היבשתית, אז שפה זו משתלמת בעיקר ב־App Store. בכל זאת לתרגם את האפליקציה ואת דף Google Play.
- אין רווחים בין מילים, אין ריבוי.
- לוודא גופן מתאים וגובה שורה מספיק.

### אינדונזית
- **הערה טכנית:** תיקיית המשאבים באנדרואיד היא

```
values-in
```

ולא לפי הקוד המודרני.

- אין ריבוי — צורת other בלבד.
- פנייה ב־kamu.

### פולנית
- **ריבוי בצורות:**

```
one, few, many, other
```

- הטקסט מתארך עד 30%.
- לנסח בלי להניח את מין השחקן.

### סינית מסורתית
- **לא להמיר אוטומטית מהסינית המפושטת.** לתרגם בנפרד, עם המונחים המקובלים בטייוואן ובהונג קונג.
- אין רווחים, אין ריבוי.

### וייטנאמית
- ניקוד מוערם מעל ומתחת לאותיות. לבדוק שאין חיתוך בגובה, במיוחד בכפתורים ובשורה אחת.
- אין ריבוי — צורת other בלבד.

### תאית
- **אין רווחים בין מילים.** לבדוק ששבירת השורות תקינה.
- סימנים גבוהים מעל ומתחת לאותיות — לבדוק חיתוך אנכי.
- ספרות מערביות בלבד, לא ספרות תאיות.
- אין ריבוי — צורת other בלבד.

### הולנדית
- מילים מורכבות ארוכות, הטקסט מתארך עד 35%.
- פנייה ב־je.

## 5. בדיקות לפני שחרור

להפעיל שפות בדיקה מדומות בגרסת הדיבאג, כדי לתפוס חיתוכים ומחרוזות שלא תורגמו עוד לפני התרגום האמיתי:

```kotlin
buildTypes {
    debug {
        isPseudoLocalesEnabled = true
    }
}
```

לבדוק בשפות המדומות

```
en-XA
```

(טקסט מוארך) ו־

```
ar-XB
```

(ימין לשמאל).

לכל שפה, אחרי התרגום:

1. לעבור על כל מסכי האפליקציה ולוודא שאין טקסט באנגלית שנשאר.
2. לבדוק שאין חיתוך טקסט בכפתורים, כותרות, דיאלוגים והתראות.
3. לבדוק את המשחק החי מול שחקן אחר — הודעות במהלך המשחק ובסופו.
4. לבדוק את מצייני המקום ואת הריבוי עם 0, 1, 2, 5, 11, 21 ו־100.
5. לבדוק שהבחירה בשפה בהגדרות המערכת מחליפה את שפת האפליקציה.
6. לספור תווים בכל שדות החנות.

## 6. סדר עבודה לכל שפה

1. לתרגם את קובץ המחרוזות המלא, כולל ריבוי.
2. להוסיף את השפה לקובץ הגדרת השפות.
3. להריץ את הבדיקות מסעיף 5.
4. לכתוב את טקסטי Google Play.
5. לכתוב את טקסטי App Store.
6. לעבור לשפה הבאה ברשימה.
