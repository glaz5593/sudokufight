# מטריצת כיסוי: מסמך השפות מול התוכנית

כל משפט או דרישה ב־[source-instructions.md](source-instructions.md) (המספר בסוגריים הוא השורה), איפה התוכנית ב־[plan.md](plan.md) מטפלת בהם, ואיך.

**הסטטוסים:**
- **מכוסה:** נעשה כמו במסמך.
- **מותאם:** נעשה, אבל בדרך של React Native.
- **שאלה למשה:** תלוי בהחלטה בסעיף 7 בתוכנית.
